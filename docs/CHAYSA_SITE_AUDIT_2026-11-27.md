# گزارش ممیزی فقط‌خواندنی دامنه چایسا — 2026-11-27

- محدوده: صفحه اصلی، صفحه محصولات، صفحه دعوت، endpoint سلامت و API عمومی محصولات؛ تطبیق با کد شاخه `chaysa-backup`، دو سند مرجع و وضعیت Production در Railway.

## یافته‌های تأییدشده

### 1. دسترسی زنده
- `https://chaysa.ir/` با عنوان «چایسا | فروشگاه اینترنتی» پاسخ داد.
- `http://chaysa.ir/` به HTTPS هدایت شد.
- صفحه `/products.html` و `/invitation.html?style=luxury` قابل دریافت بودند.
- `GET /api/health` پاسخ `200` با بدنه `{"ok":true,"service":"chaysa-backup"}` داد.
- در زمان ممیزی، صفحه اصلی محتوای فروشگاه را نمایش می‌داد؛ بنابراین ثبت قدیمی‌تر پرونده مادر درباره نمایش صرفِ صفحه روزشمار در 2026-11-22 با مشاهده زنده این تاریخ یکسان نیست و باید به‌عنوان سابقه تاریخی، نه وضعیت فعلی، خوانده شود.

### 2. مغایرت مهم کاتالوگ محصولات
- `GET /api/products` در دامنه زنده پاسخ `[]` داد؛ API در زمان آزمون هیچ محصول فعالی برنگرداند.
- بااین‌حال، صفحه زنده `/products.html` تعداد 48 محصول ثابت را نمایش داد: 25 چای، 14 دمنوش و 9 ادویه.
- در کد `products.html` شاخه `chaysa-backup`، فهرست 48 محصول به‌صورت HTML ثابت داخل صفحه قرار دارد. اسکریپت فقط وقتی فهرست زنده را جایگزین می‌کند که پاسخ API آرایه غیرخالی باشد؛ در نتیجه پاسخ خالی API باعث باقی‌ماندن و نمایش محصولات ثابت می‌شود.
- در `server.js` مسیر `GET /api/products` خروجی `readProducts()` را برمی‌گرداند. فایل معتبر خالی `/data/products.json` به‌صورت آرایه خالی پذیرفته می‌شود و fallback به seed فقط هنگام خطای خواندن/تجزیه فایل انجام می‌شود.
- این رفتار با تصمیم ثبت‌شده مالک مبنی بر خالی‌ماندن بخش محصولات تا دستور صریح بعدی تعارض دارد.
- **شدت: بالا.** محصولات در رابط مشتری نمایش داده می‌شوند، درحالی‌که API کاتالوگ خالی گزارش می‌کند. این مغایرت باید پیش از معرفی سایت به‌عنوان نسخه آماده، در شاخه اصلاحی بررسی و رفع شود. در این ممیزی هیچ محصولی حذف یا اضافه نشد.

### 3. وضعیت Railway و دامنه
- پروژه Railway: `chaysa-backup`؛ سرویس: `chaysa-backup-store`؛ محیط: `production`.
- شاخه متصل سرویس: `chaysa-backup`؛ پورت مقصد: 3000؛ volume پایدار در `/data`.
- آخرین deployment قابل مشاهده هنگام ممیزی: شناسه `1dd09714-7fcc-487a-9e7c-d98403db57ed`، وضعیت `SUCCESS`، زمان ایجاد 2026-11-24T02:13:50Z، commit `ee70cfcda8b369a5f0e87ff8a793713ad87a3369`.
- Railway فقط دامنه سرویس `chaysa.up.railway.app` را در این سرویس فهرست می‌کند و هیچ custom domain متصل به آن گزارش نمی‌دهد.
- با وجود این، دامنه `chaysa.ir` محتوای چایسا و پاسخ API سلامت سرویس را ارائه می‌کند. لایه‌ای که دامنه را به برنامه می‌رساند (DNS، سرور واسط یا reverse proxy) از شواهد در دسترس این ممیزی تعیین نشد.
- **وضعیت: نیازمند تطبیق زیرساخت دامنه.** نبود custom domain در Railway به‌تنهایی اثبات خرابی دامنه نیست؛ صرفاً نشان می‌دهد اتصال مستقیم دامنه در تنظیمات فعلی این سرویس ثبت نشده است.

### 4. محدودیت‌های این ممیزی
- پاسخ `/api/health` فقط پاسخ‌دهی اولیه برنامه را تأیید می‌کند؛ سلامت همه وابستگی‌ها، volume و گردش سفارش را اثبات نمی‌کند.
- محتوای volume `/data` مستقیماً خوانده نشد.
- ورود مدیریتی، ثبت سفارش، پرداخت، ارسال پیام تلگرام، پاسخ پرسش‌وپاسخ و رهگیری به‌صورت عملیاتی آزمایش نشدند.
- دسترسی SSH به سرور دامنه و بررسی مستقیم Nginx، DNS zone و گواهی TLS از این ممیزی انجام نشد.
- آماده‌بودن فروشگاه برای فروش یا صحت کامل گردش‌های تجاری از این نتایج قابل استنتاج نیست.
