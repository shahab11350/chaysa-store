# CHAYSA CHECK — Phase 2 Owner Preview

این سرویس یک پیش‌نمایش ایستا و خصوصی برای بازبینی مالک است.

## محدودیت‌های قطعی
- هیچ اتصال به سایت یا API عملیاتی چایسا ندارد.
- هیچ سفارش، مشتری، پرداخت، موجودی یا پیام واقعی دریافت/ارسال نمی‌کند.
- داده‌ها و محتوای صفحه صرفاً نمایشی‌اند.
- دسترسی با HTTP Basic Auth محافظت می‌شود.
- برای اجرا باید دو متغیر `CHECK_PREVIEW_USER` و `CHECK_PREVIEW_PASSWORD` تنظیم شوند.
- تا تأیید مالک، این پیش‌نمایش به Production منتقل نمی‌شود.

## اجرا
`npm start`
